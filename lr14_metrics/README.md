### Висновок для команди delta
Команда delta працює в контексті монолітної спадкової системи (`lead_time` = 30 годин, `recovery_hours` = 4), тому порівнювати її напряму з мікросервісними командами (alpha та beta) не можна. Проте показник часу відновлення (4 години) є добрим для моноліту. Як PM, я спершу фокусуюся на оптимізації процесу тестування та автоматизації регресії для зменшення часу доставки змін.

## 4. Метрика, яку найлегше накрутити

- **Metric ID:** `MT-01` (Cycle Time P85).
- **Як накрутити без корисної роботи:** Штучно закривати невеликі тестові завдання або розбивати кожну задачу на мікроскопічні підзадачі, які виконуються за пів години, а складні проблеми ігнорувати чи замовчувати.

- **Захисний захід:** Використання комплексного погляду в парі з Throughput та обов'язковий контроль проходження Definition of Done.
