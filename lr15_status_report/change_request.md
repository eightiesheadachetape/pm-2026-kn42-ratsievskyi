# Запит на зміну (Change Request)

## 1. Опис зміни
Впровадження обов'язкової підтримки авторизації через єдиний акаунт академії (SSO/OAuth2) та журналу доступу до персональних даних згідно з вимогою спонсора (`course_event`).

## 2. Таблиця розрахунку впливу
- Стеля годин варіанта V12: **2200 годин**
- Бюджет варіанта V12: **1 100 000 грн**
- Ставка години: **500 грн/год** (1100000 / 2200)
- Години, надані спонзором (10%): **220 годин**
- Години зміни (оцінка S-16 + S-17): **80 годин**
- **Висновок:** Запит укладається в межі наданих спонзором ресурсів (80 годин <= 220 годин).

## 3. Варіанти дій
1. **Прийняти зміну і компенсувати обсяг:** Додати S-16 та S-17, винісши S-14 у REL-2 (обраний варіант).
2. **Розсунути дедлайн релізу:** Зсунути дату випуску REL-1 на 2 тижні без видалення історій.
3. **Відхилити зміну:** Відмовитися від інтеграції SSO, залишивши базову локальну авторизацію.
