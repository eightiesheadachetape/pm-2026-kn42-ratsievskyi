## 2. Як рахувалася симуляція

| Поле | Значення |
| --- | --- |
| Інструмент | Python-скрипт симуляції методом Монте-Карло |
| Прогонів | 10000 |
| Що тягнеться випадково | Випадковий вибір значення velocity з наявних історій спринтів [12, 13] |
| Як рахується дата прогнозу | Останній день спринта, на якому закінчується робота: для сценарію «весь перший реліз» кінець спринта 1 плюс (P − 1) × 14 днів, для сценарію залишку кінець останнього спринта плюс P × 14 днів |

Код симуляції на Python:
```python
import random

simulations = 10000
velocity_history = [12, 13]


def monte_carlo(remaining):
  results = []
  for _ in range(simulations):
    sprints = 0
    rem = remaining
    while rem > 0:
      rem -= random.choice(velocity_history)
      sprints += 1
    results.append(sprints)
  results.sort()
  p50 = results[int(len(results) * 0.50)]
  p85 = results[int(len(results) * 0.85)]
  return p50, p85


print("Rel-1:", monte_carlo(50))
print("Remaining:", monte_carlo(25))
