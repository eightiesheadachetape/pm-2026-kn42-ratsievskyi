## 3. Спірні призначення A

- **A-05 (Приймальне тестування першого релізу):** Роль **A** закріплена за Керівником практики від кафедри (ST-02), оскільки саме академічний підрозділ ухвалює офіційне рішення про готовність платформи до експлуатації, хоча технічну перевірку виконують QA та студенти.
- **A-06 (Рішення про зміну обсягу):** Роль **A** винесена на Завідувача навчальної частини (ST-01), оскільки зміна архітектурних вимог (наприклад, інтеграція SSO) зачіпає університетські регламенти та бюджетні рамки.

## 4. Ціна погоджень

Найбільша кількість консультантів (**C**) спостерігається в активності `A-01` та `A-05`, що вимагає додаткових 2–3 днів на узгодження між академічними підрозділами та командою розробки.
