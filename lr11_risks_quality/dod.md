# Definition of Done (DoD)

Студент: Олексій Рацієвський (eightiesheadachetape). Тема: Платформа обліку практик і стажувань: студент, база практики, керівник, звіт.

Definition of Done — це єдиний стандарт якості для всіх User Stories проєкту, який визначає готовність історії до випуску в реліз.

## Умови завершеності історії

1. **Код реалізовано та перевірено:** Повністю написано програмний код історії відповідно до архітектурних паттернів платформи.
2. **Самоперевірка за чеклистом:** Автор коду провів самоперевірку (статичний аналіз коду, відсутність критичних попереджень компілятора).
3. **Критерії приймання виконані:** Усі Acceptance Criteria, описані в беклозі для цієї історії, перевірені та проходять успішно (включаючи негативні сценарії).
4. **Базове функціональне тестування:** Проведено успішне ручне тестування основного та альтернативних сценаріїв у Docker-середовищі.
5. **Документація оновлена:** Оновлено коментарі у коді та схеми БД (за потреби).

## Чого DoD свідомо не вимагає

- **Cross-code review другою людиною:** Оскільки розробка здійснюється одним виконавцем, обов'язковий перегляд коду іншим розробником замінено на авто-лінтер та самоперевірку на наступний день.
- **Повне автоматичне 100% покриття E2E тестами:** Створення сквозних автотестів відкладено для економії часу розробки на користь якісного функціонального тестування.
